Realizei web scraping do site henet.com.br, extraindo e normalizando textos. Os dados foram segmentados, transformados em tokens e processados pela API do ChatGPT para gerar embeddings, armazenados em uma base vetorial. 
O sistema permite consultas semânticas, utilizando a IA para responder com base nos dados coletados.

O arquivo com o código fonte é o main.ipynb.
